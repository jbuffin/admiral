# Admiral

A visual dashboard for [Commodore Launcher](https://github.com/jbuffin/commodore-launcher). Admiral is the front end to the `commodore` command: your work queues on the left, a cartoon ocean of running sessions in the middle, and one marina per Commodore profile on the right. Drag a task onto a harness's dock to launch it; tap a ship to attach to its terminal.

This repo is in the design phase. No code yet.

![Admiral harbor](designs/screenshots/harbor-1440x900.png)

## Layout

- `designs/`: the clickable prototype, screenshots, design tokens, SVG assets and source design files. Start with `designs/README.md`.
- `docs/spec.md`: what Admiral does, with a "done when" check for each behavior.
- `docs/architecture.md`: the proposed shape of the build.
- `docs/adr/`: decisions.
- `docs/open-questions.md`: what still needs deciding, mostly where Commodore Launcher needs to grow.
- `GLOSSARY.md`: the words Admiral uses and how they map to Commodore Launcher's.
